# Mechatronics Engineer Portfolio

A modern and responsive portfolio website designed and developed for a Mechatronics Engineer to showcase professional experience, technical skills, engineering projects, certifications, and contact information.

## 🚀 Features

* Modern and clean UI/UX design
* Fully responsive across all devices
* Smooth scrolling and interactive animations
* Project showcase section
* Skills and technologies section
* About Me section
* Contact form integration
* Fast loading and optimized performance

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Responsive Design
* CSS Animations & Transitions


## 🎯 Purpose

This portfolio was created to establish a strong professional online presence, highlight engineering achievements, and provide an easy way for potential employers, clients, and collaborators to connect.

## 📱 Responsive Design

The website is optimized for:

* Desktop
* Tablet
* Mobile Devices
